# 🐉 Dragon 3D Website

Interactive 3D dragon experience in the browser.

## Features
- Real-time 3D model (.glb) rendering
- Orbit/scroll-based camera animation
- Cinematic dark theme with lighting & effects
- Responsive and performance-optimized

## Tech Stack
React · Three.js · React Three Fiber · Vite

## Run Locally
git clone https://github.com/<your-username>/dragon-3d-website.git
cd dragon-3d-website
npm install
npm run dev
